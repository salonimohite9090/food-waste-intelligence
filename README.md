# FOOD WASTE INTELLIGENCE
### Inventory Loss | Operational Efficiency | Sustainability Analytics

An interactive food waste analytics dashboard designed to explore inventory loss, identify waste patterns, and compare operational performance across business types.

## Project Overview
This project analyzes a synthetic food inventory dataset containing 8,000 records from 2025. It presents key waste metrics and interactive visualizations to help users investigate food waste patterns.

## Key Performance Indicators
- Total Food Waste
- Total Purchased Quantity
- Total Units Sold
- Waste Rate

## Dashboard Visualizations
1. **Category Waste Fingerprint** – compares waste across food categories.
2. **Waste Calendar Intelligence** – explores daily waste patterns across months.
3. **Waste Pathways** – shows relationships between food categories and recorded waste reasons.
4. **Waste Reason Treemap** – compares the contribution of different waste reasons.
5. **Business Performance Matrix** – compares waste quantity and waste rate across business types.

## Interactive Features
- Year and month filters
- Business type filter
- Food category filter
- Waste reason filter
- Interactive chart selections
- Reset filters

## Dataset Note
The dataset is synthetic and contains 8,000 inventory records. The dashboard is an analytical portfolio project, not a report of actual business operations or measured environmental impact.

## Project Objective
To demonstrate data analysis, KPI reporting, interactive visualization, and dashboard design through a practical food waste analytics use case.
